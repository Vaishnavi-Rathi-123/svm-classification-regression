# Support Vector Machines (SVM) – Classification & Regression

This repository demonstrates the implementation of **Support Vector Machine (SVM)** for both:

- Classification (SVC)
- Regression (SVR)

The project focuses on understanding margin maximization, decision boundaries, kernel functions, and hyperparameter tuning using cross-validation.

---

## 📌 Project Overview

Support Vector Machine is a supervised machine learning algorithm used for:

- Classification problems
- Regression problems

This project includes:

- SVM Classifier implementation
- SVM Regressor implementation
- Model evaluation metrics
- Hyperparameter tuning using GridSearchCV

---

## 📚 Concepts Covered

- Hard Margin vs Soft Margin
- Support Vectors
- Decision Boundary
- Kernel Trick (Linear, Polynomial, RBF)
- Regularization parameter (C)
- Gamma parameter
- Cross-validation
- GridSearchCV for model optimization
